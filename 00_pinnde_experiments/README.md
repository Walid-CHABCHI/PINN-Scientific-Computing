# pinnDE Experiments — 1D Heat Equation

First experiments using the [pinnDE](https://pinnde.readthedocs.io/) library (TensorFlow).

- `pinnde_heat_forward.ipynb`: forward problem (1+1D), Gaussian initial condition, comparison with the analytical solution (max error ≈ 0.014)
- `pinnde_heat_inverse.ipynb`: inverse problem — identifying diffusivity α = 0.08 from 400 noisy data points
- `figures/PDE-solution-pred.png`, `figures/PDE-epoch-loss.png`: figures generated by pinnDE plotters
